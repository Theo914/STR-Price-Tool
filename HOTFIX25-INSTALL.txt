HOTFIX 25 — BOOKING SOURCE-RESPONSE PARSER
==========================================

Hotfix 25 parses Booking's original navigation response in memory, which is the
same underlying HTML exposed by Ctrl+U. It keeps only bounded pricing fields,
never stores the raw response, records exact rejection reasons, and adds a real
network-free import-booking-source fallback for locally saved source files.
