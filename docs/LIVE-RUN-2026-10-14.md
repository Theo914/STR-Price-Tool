## Defects found live and fixed

1. Airbnb identity read no licence when the page had embedded state (the
   normal case) and the licence regex only knew EU formats. Identity now also
   compares the subject's licence against every licence-shaped token on the
   candidate page, normalised (case/spaces/dashes ignored). WA `STRA…` and NSW
   `PID-STRA-…` were added to the regex.
2. Token scan stopped after 20,000 tokens; Airbnb pages have ~67,000.
3. Older Airbnb listings (`/im/pictures/<uuid>.jpg`, no `Hosting-<id>`) failed
   identification; title/bedrooms/baths/guests now come from `og:` metadata
   and `personCapacity`.
4. Airbnb's all-in price display ("$595 AUD for 1 night", breakdown ending in
   "Price after discount") had no recognised total, so pricing failed.
5. Booking text search degrades to `/hotel/index.html`, which was accepted as
   a property. It is now rejected; a coordinate (`dest_type=latlong`) search
   was added; the provider waits for Booking's 202 interstitial to hand over
   and reports a throttled/stripped page instead of "0 candidates".
6. Bing returning unrelated results ("no_ota_links") no longer ends the
   search; the next engine is tried.

## Environment notes

- `PARITY_TRUST_ENV_PROXY=1` lets the HTTP client use `HTTPS_PROXY` (cloud
  containers). Windows behaviour is unchanged.
- `PARITY_BROWSER_EXECUTABLE=/path/to/chromium` for non-Windows hosts.
- Google serves its "unusual traffic" page to datacenter IPs; on a home
  connection the operator can clear it in the visible browser window.
